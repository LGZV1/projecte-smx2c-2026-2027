### Ferronetwork


### 

Lucas Gagliano · SMX2 · INS Palamós

#### 1. De què va el projecte
El projecto va principalmente de crear una red interna conectando dos empresas entre ellas de una forma más privada sin tener que pasar datos por fuentes externas como google o alguna otras, estilo: gmail, thunderbird, drive...
La idea original consiste de varias partes, primera parte crear dos empresas con sus servidores donde estarán conectados entre ellos a través de una intranet, aparte esas conexiones se harán con VPN para garantizar una privacidad mayor para los usuarios que se conecten, también los datos van a ir cifrados y vamos a hacer con atlassian un lugar seguro para trabajar.

Abast:

Xarxa privada: connexió entre dues seus mitjançant servidors
VPN: accés remot segur amb ZeroTier o WireGuard
Intranet: pàgina web funcional accessible només mitjançant VPN
Servidor de correu: creació de diversos comptes per als usuaris
Comunicació tipus Slack: espai de treball per intercanviar missatges i fitxers
Base de dades: emmagatzematge de la informació dels usuaris
Proxy i firewall: control i protecció de les connexions
Seguretat: xifratge de les comunicacions i control d'accessos
Pentesting: realització de proves de hacking per detectar vulnerabilitats i comprovar la seguretat de la xarxa
